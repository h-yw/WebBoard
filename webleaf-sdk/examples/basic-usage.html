🌿 WebLeaf SDK 示例

以下示例展示如何通过 window.webLeaf 调用 HarmonyOS 原生能力。

SDK 已自动注入 —— 🟢 检测中...

getAppInfo() 基础

获取应用信息、SDK 版本、网络状态、设备信息

getVersion() 基础

获取 SDK 版本号、容器版本号、API 级别

hasMethod() 基础

检测某个方法在当前容器中是否可用

modifyNavStyle() UI

修改查看器导航栏样式（0=隐藏，1=透明，-1=设标题）

setClipboard() 工具

将文本写入系统剪贴板

vibrate() 工具

触发设备震动

Error Handling 最佳实践

所有 JSBridge 调用返回标准错误码

window.webLeaf.getAppInfo()
  .then(data => { /* { status: 'ok', code: 'OK', data: {...} } */ })
  .catch(err => { /* { code: 'PERMISSION_DENIED', message: '...' } */ })
