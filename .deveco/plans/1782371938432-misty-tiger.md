# EditPage UI/UX 全面优化计划

## 目标
优化卡片编辑页面的UI/UX，提升用户编辑应用的体验，使页面更整洁、交互更流畅、视觉更统一。

## 范围
- **包含**：EditPage.ets 的布局、交互、视觉优化
- **不包含**：其他页面的修改、数据模型变更、导航架构调整

## 当前状态分析

### 现有代码问题

1. **布局问题**：
   - `SectionTitle` 与输入框间距不够协调
   - 图标选择区域布局不够清晰
   - 状态消息显示位置不够明显
   - 保存按钮位置固定，未考虑键盘弹出适配

2. **交互问题**：
   - 输入框缺少焦点管理
   - 没有输入验证的实时反馈
   - 保存按钮禁用状态视觉反馈不够明显
   - 没有返回确认机制（防止误操作丢失修改）

3. **视觉问题**：
   - 图标预览区域与按钮对齐方式可优化
   - 状态消息样式不够统一
   - 整体视觉层次可更清晰

4. **UX改进点**：
   - 缺少输入框字符计数
   - 键盘弹出时布局调整不完善
   - 保存成功视觉反馈可增强
   - 图标选择交互流程可优化

## 设计方案

### 1. 布局优化

**采用卡片式表单布局**：
- 将表单分组到卡片容器中，提升视觉层次
- 统一表单项间距（使用 `Column({ space: 16 })`）
- 优化标题与输入框的间距关系
- 添加适当的内边距和外边距

**具体实现**：
```typescript
// 表单卡片容器
Column({ space: 16 }) {
  // 应用名称卡片
  Column({ space: 8 }) {
    Text('应用名称')
      .fontSize(13)
      .fontWeight(FontWeight.Medium)
      .fontColor($r('app.color.app_text_muted'))
    
    TextInput({ placeholder: '输入应用名称', text: this.appName })
      .fontSize(15)
      .height(48)
      .borderRadius(10)
      .backgroundColor($r('app.color.app_card_bg'))
      .padding({ left: 12, right: 12 })
      .onChange((value: string) => {
        this.appName = value
      })
  }
  .width('100%')
  .padding(16)
  .borderRadius(12)
  .backgroundColor($r('app.color.app_card_bg'))
}
.width('90%')
.margin({ top: 16 })
```

### 2. 交互优化

**输入验证与反馈**：
- 添加实时输入验证（名称长度、描述字符计数）
- 优化键盘弹出时的布局（使用 `Scroll` 组件自动调整）
- 添加返回确认机制（检测是否有未保存的修改）

**具体实现**：
```typescript
// 添加状态变量
@State hasUnsavedChanges: boolean = false
@State nameCharCount: number = 0
@State descCharCount: number = 0

// 输入变化时更新状态
.onChange((value: string) => {
  this.appName = value
  this.nameCharCount = value.length
  this.hasUnsavedChanges = true
})

// 返回确认机制
onBackPress(): boolean {
  if (this.hasUnsavedChanges) {
    this.getUIContext().showAlertDialog({
      title: '未保存的修改',
      message: '您有未保存的修改，确定要离开吗？',
      primaryButton: {
        value: '离开',
        action: () => {
          this.navPathStack?.pop()
        }
      },
      secondaryButton: {
        value: '取消',
        action: () => {}
      }
    })
    return true
  }
  return false
}
```

### 3. 视觉优化

**图标选择区域优化**：
- 优化图标预览与按钮的布局对齐
- 添加图标选择的视觉反馈
- 优化按钮样式和状态

**状态提示优化**：
- 统一状态消息的样式和位置
- 添加保存成功的视觉反馈（Toast + 动画）
- 优化错误提示的显示方式

**具体实现**：
```typescript
// 图标选择区域优化
Row({ space: 16 }) {
  // 图标预览
  if (this.logoType === LogoType.CUSTOM && this.logoUri.length > 0) {
    Image('file://' + this.logoUri)
      .width(64)
      .height(64)
      .borderRadius(14)
      .objectFit(ImageFit.Cover)
      .border({ width: 2, color: $r('app.color.app_primary') })
  } else {
    Stack() {
      Text(this.getInitial())
        .fontSize(28)
        .fontWeight(FontWeight.Bold)
        .fontColor(Color.White)
    }
    .width(64)
    .height(64)
    .borderRadius(14)
    .linearGradient({
      angle: 135,
      colors: [['#6366F1', 0.0], ['#8B5CF6', 1.0]]
    })
    .alignContent(Alignment.Center)
  }

  // 按钮区域
  Column({ space: 8 }) {
    Button() {
      Row({ space: 4 }) {
        SymbolGlyph($r('sys.symbol.picture'))
          .fontSize(14)
          .fontColor([Color.White])
        Text('选择图片')
          .fontSize(13)
          .fontColor(Color.White)
      }
    }
    .height(36)
    .borderRadius(8)
    .backgroundColor($r('app.color.app_primary'))
    .onClick(() => {
      this.pickLogoImage()
    })

    if (this.logoType === LogoType.CUSTOM) {
      Button() {
        Row({ space: 4 }) {
          Text('Aa')
            .fontSize(14)
            .fontColor($r('app.color.app_text_secondary'))
          Text('使用首字母')
            .fontSize(13)
            .fontColor($r('app.color.app_text_secondary'))
        }
      }
      .height(36)
      .borderRadius(8)
      .backgroundColor($r('app.color.app_card_bg'))
      .border({ width: 1, color: $r('app.color.app_border') })
      .onClick(() => {
        this.resetLogo()
      })
    }
  }
  .layoutWeight(1)
}
.width('100%')
.padding(16)
.borderRadius(12)
.backgroundColor($r('app.color.app_card_bg'))
```

### 4. 保存按钮优化

**保存按钮状态与反馈**：
- 优化禁用状态的视觉反馈
- 添加保存过程中的加载状态
- 保存成功后显示 Toast 并延迟返回

**具体实现**：
```typescript
@State isSaving: boolean = false

// 保存按钮
Button() {
  if (this.isSaving) {
    LoadingProgress()
      .width(20)
      .height(20)
      .color(Color.White)
  } else {
    Row({ space: 6 }) {
      SymbolGlyph($r('sys.symbol.save'))
        .fontSize(16)
        .fontColor([Color.White])
      Text('保存修改')
        .fontSize(16)
        .fontWeight(FontWeight.Medium)
        .fontColor(Color.White)
    }
  }
}
.height(50)
.borderRadius(12)
.backgroundColor(this.appName.trim().length > 0 ? $r('app.color.app_primary') : $r('app.color.app_text_disabled'))
.width('90%')
.margin({ top: 28, bottom: 32 })
.enabled(this.appName.trim().length > 0 && !this.isSaving)
.onClick(() => {
  this.handleSave()
})
```

## 风险与兼容性

### 风险
1. **状态管理复杂性**：新增状态变量可能影响现有逻辑
2. **布局变化**：卡片式布局可能影响整体视觉风格
3. **交互变化**：返回确认机制可能影响用户习惯

### 兼容性
- 保持现有导航架构不变
- 保持数据模型和存储逻辑不变
- 保持与其他页面的接口一致

## 回滚方案

如果优化效果不理想或出现问题：

1. **代码回滚**：恢复 EditPage.ets 到原始版本
2. **资源回滚**：如果添加了新资源，删除相关资源文件
3. **测试验证**：回滚后测试基本功能是否正常

## 实现注意事项

1. **ArkTS 语法**：确保代码符合 ArkTS 语法规范
2. **状态管理**：使用 `@State` 管理组件状态
3. **资源引用**：使用 `$r('app.color.xxx')` 引用颜色资源
4. **组件样式**：保持与现有页面一致的视觉风格
5. **交互逻辑**：保持现有业务逻辑不变，只优化UI/UX
