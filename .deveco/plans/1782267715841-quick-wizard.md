# 替换字符图标为系统图标

## 图标映射

| 用途 | 当前字符 | 系统图标 | 文件 |
|------|----------|----------|------|
| 搜索 | 🔍 | `sys.symbol.ic_public_input_search` | Index.ets |
| 列表视图 | ☰ | `sys.symbol.ic_public_view_list` | Index.ets |
| 网格视图 | ▦ | `sys.symbol.ic_public_view_grid` | Index.ets |
| 设置 | ⚙️ | `sys.symbol.gearshape` | Index.ets |
| 添加 | ＋ | `sys.symbol.ic_public_add` | Index.ets |
| 空状态 | 📦 | 暂无，保留 emoji | Index.ets |
| 预设 | 📋 | 暂无，保留 emoji | Index.ets |
| 保存 | 💾 | `sys.symbol.save` | EditPage.ets |
| 图片 | 🖼️ | `sys.symbol.picture` | EditPage.ets |

## 使用方式

```typescript
// Before:
Text('🔍').fontSize(16)

// After:
SymbolGlyph($r('sys.symbol.ic_public_input_search'))
  .fontSize(16)
  .fontColor([$r('app.color.app_text_muted')])
```

**注意：** `SymbolGlyph` 的 `.fontColor()` 接受数组格式 `ResourceColor[]`。

## Verification

| 检查项 | 预期 |
|--------|------|
| 编译通过 | 无错误 |
