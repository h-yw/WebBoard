# 使用 AppStorage 修复导入后列表不更新

## 问题

导入后返回首页，列表不更新。ImportPage 保存数据后直接 pop()，Index 不知道数据已变化。

## 方案

使用 AppStorage 实现跨 Navigation 边界的状态同步。

## 改动

### 1. Index.ets

移除原有的 `@State dataChanged` 和 `onPageShow` 中的检查逻辑，改用 `@StorageProp @Watch`：

```typescript
@StorageProp('dataChanged') @Watch('onDataChanged') dataChanged: boolean = false

onDataChanged(): void {
    if (this.dataChanged) {
      this.loadApps()
      AppStorage.setOrCreate('dataChanged', false)
    }
}
```

移除 `onPageShow` 中的 `dataChanged` 检查（因为 `@Watch` 会自动触发）。

### 2. ImportPage.ets

导入成功后设置 AppStorage：

```typescript
await storageMgr.add(item)
AppStorage.setOrCreate('dataChanged', true)
```

### 3. EditPage.ets

保存成功后设置 AppStorage：

```typescript
await storageMgr.saveAll(items)
AppStorage.setOrCreate('dataChanged', true)
```

### 4. deleteApp

`deleteApp` 在 Index 内部调用，直接更新 `this.appList`，不需要通过 AppStorage。但为了统一，也可以设置 AppStorage。

## Verification

| 检查项 | 预期 |
|--------|------|
| 编译通过 | 无错误 |
| 导入后返回 | 列表自动更新 |
| 编辑后返回 | 列表自动更新 |
| 删除应用 | 列表立即更新 |
| 从 ViewerPage/SettingsPage 返回 | 不触发不必要的重载 |
