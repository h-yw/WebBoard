# WebBoard 迭代规划

## 产品定位

WebBoard 是一个 HarmonyOS 应用，用于管理和渲染 HTML 内容。用户可以导入 HTML 文件或目录，以卡片形式展示，点击即可使用。定位为"HTML 应用管理器"。

## 迭代路线

### 第一阶段：体验打磨

> 预计周期：1-2 周

| 功能 | 说明 | 复杂度 | 状态 |
|------|------|:---:|:---:|
| 卡片网格布局 | 首页改为 2 列网格，Logo 更大更醒目，充分利用屏幕空间 | 低 | ✅ 已完成 |
| 左滑删除 | 卡片左滑出现删除按钮，替代长按弹窗，更符合 HarmonyOS 手势习惯 | 低 | ⏭️ 跳过（与 Grid 冲突） |
| 空状态优化 | 无应用时显示大图标 + 引导文字 + 一键导入按钮，而非简单文字提示 | 低 | ✅ 已完成 |
| 搜索增强 | 搜索框支持实时高亮匹配结果，无结果时显示"导入新应用"快捷入口 | 低 | ⏭️ 跳过（当前筛选已够用） |
| 操作反馈优化 | 删除后显示 Toast + 撤销按钮（3 秒内可撤销），防止误删 | 中 | ⏭️ 跳过（当前确认流程已满足） |
| 系统图标替换 | 将 emoji/字符图标替换为 HarmonyOS 官方 SymbolGlyph 系统图标 | 低 | ✅ 已完成 |
| 网格/列表双模式 | 支持在网格和列表两种布局间切换，持久化用户偏好 | 低 | ✅ 已完成 |

| 通知提醒 | 定期提醒用户使用收藏的应用，或提醒长时间未使用的应用 | 低 | 待开发 |
