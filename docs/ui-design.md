# UI 设计规范

## 设计原则

1. **简洁清晰**：界面简洁，信息层次分明
2. **一致性**：统一的色彩、间距、圆角规范
3. **可访问性**：文字大小适中，颜色对比度足够
4. **响应式**：适配不同屏幕尺寸

## 色彩规范

### 主色调

| 颜色 | 色值 | 用途 |
|------|------|------|
| 主色紫 | `#6366F1` | 按钮、图标渐变、进度条 |
| 主色紫深 | `#8B5CF6` | 渐变结束色 |
| 成功绿 | `#10B981` | 预设来源标签 |

### 中性色

| 颜色 | 色值 | 用途 |
|------|------|------|
| 标题黑 | `#0F172A` | 主标题、应用名称 |
| 正文深 | `#1E293B` | 正文内容 |
| 正文中 | `#334155` | 次要内容 |
| 正文浅 | `#64748B` | 描述文字 |
| 占位灰 | `#94A3B8` | 占位文字 |
| 边框灰 | `#E2E8F0` | 分割线、边框 |
| 背景灰 | `#F1F5F9` | 页面背景 |
| 输入框灰 | `#F8FAFC` | 输入框背景 |

### 阴影

| 阴影 | 参数 | 用途 |
|------|------|------|
| 卡片阴影 | `radius: 6, color: '#08000000', offsetY: 1` | 卡片悬浮效果 |
| 按钮阴影 | `radius: 4, color: '#20000000', offsetY: 2` | 按钮立体感 |

## 间距规范

| 间距 | 数值 | 用途 |
|------|------|------|
| 页面边距 | 16px | 页面左右内边距 |
| 卡片间距 | 12px | 列表项之间间距 |
| 卡片内边距 | 14px | 卡片内部内容边距 |
| 元素间距 | 6-8px | 相关元素之间间距 |

## 圆角规范

| 圆角 | 数值 | 用途 |
|------|------|------|
| 卡片圆角 | 12px | 卡片、图标容器 |
| 按钮圆角 | 8px | 按钮 |
| 标签圆角 | 4px | 来源标签 |
| 进度条 | 0px | 全宽进度条 |

## 字体规范

| 元素 | 字号 | 字重 | 颜色 |
|------|------|------|------|
| 页面标题 | 20px | Bold | `#0F172A` |
| 卡片标题 | 16px | Medium | `#0F172A` |
| 正文 | 14px | Normal | `#1E293B` |
| 描述文字 | 13px | Normal | `#64748B` |
| 标签文字 | 11px | Normal | Color.White |
| 辅助文字 | 10px | Normal | `#94A3B8` |

## 组件规范

### 卡片组件

```
┌─────────────────────────────────────┐
│  ┌──────┐  名称              [预设]  │
│  │  图  │  描述文字最多三行显示...    │
│  │  标  │  描述文字第二行...          │
│  └──────┘                            │
└─────────────────────────────────────┘
```

**规格**：
- 宽度：100%（减去页面边距）
- 内边距：14px
- 圆角：12px
- 阴影：柔和阴影
- 图标：56×56px，渐变紫色背景

### 按钮组件

**主按钮**：
- 高度：36-44px
- 圆角：8px
- 背景：`#6366F1`
- 文字：14-15px，白色，Medium
- 阴影：柔和阴影

**次按钮**：
- 高度：36-44px
- 圆角：8px
- 背景：白色
- 边框：1px `#4F46E5`
- 文字：14px `#4F46E5`

### 输入框组件

- 高度：44px（单行）/ 80px（多行）
- 圆角：8px
- 背景：`#F8FAFC`
- 边框：无（聚焦时显示主色边框）
- 文字：15px

### 标签组件

- 圆角：4px
- 内边距：6px 水平，2px 垂直
- 字号：11px
- 颜色：白色背景 + 白色文字

## 交互规范

### 点击反馈

- 卡片点击：跳转到查看器
- 卡片长按：弹出删除确认对话框
- 按钮点击：执行对应操作

### 加载状态

- 加载中：显示进度条
- 加载失败：显示错误信息和重试按钮
- 加载成功：显示内容

### 空状态

- 无应用时显示占位文字："暂无应用" + "点击右上角「导入」添加 HTML 应用"
